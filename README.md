Сайт "Нижний Новгород"

О проекте
Проект выполнен в рамках учебной дисциплины "Обеспечение качества функционирования компьютерных систем" для 2 курса СПО.

Тема: Многостраничный сайт о городе Нижний Новгород.
Студентка: Фионина Виктория, группа ИС-24-2
Преподаватель: Корнеев М.Д.


Структура сайта:
`index.html`: Главная страница с приветствием и слайдером фотографий Кремля 
`attractions.html`:5 достопримечательностей с всплывающими статьями 
`gallery.html`: Галерея фотографий
`history.html`: Хронология истории города с 1221 года 

Технологии:

1. HTML5 — структура страниц
2. CSS3 — стилизация, адаптивная вёрстка (Flexbox, Grid), анимации
3. JavaScript — интерактивные элементы (слайдер, модальные окна, галерея)

Функционал сайта:

Главная страница:
1. Слайдер (карусель) фотографий Кремля на 4 слайда
2. Автоматическое переключение каждые 5 секунд
3. Ручное переключение стрелками и точками
4. Карточки с основными фактами о городе

Достопримечательности:
1. 5 объектов с кратким описанием
2. При нажатии открывается модальное окно с полной статьёй
3. В статье: фото, история, адрес, интересные факты

Галерея:
1. Сетка из 6 фотографий
2. При нажатии на фото — увеличение
3. Навигация стрелками для переключения между фото
4. Точки для быстрого перехода
5. Закрытие по крестику, ESC или клику на фон

История:
1. 6 ключевых событий в хронологическом порядке
2. При наведении — всплывающая плашка с портретом и интересным фактом

Как запустить проект локально:

1. Скачать репозиторий
2. Открыть папку `Nizhniy-site`
3. Дважды кликнуть на `index.html` (откроется в браузере)
