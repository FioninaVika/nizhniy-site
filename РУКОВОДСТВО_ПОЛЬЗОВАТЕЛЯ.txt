Руководство пользователя сайтом «Нижний Новгород»
1. Общие сведения
Наименование ресурса: информационный сайт «Нижний Новгород».
Назначение: ознакомление пользователей с достопримечательностями, историей и фотоматериалами города Нижнего Новгорода.
Автор: Фионина Виктория, группа ИС-24-2.
Дисциплина: «Обеспечение качества функционирования компьютерных систем».
Преподаватель: Корнеев М.Д.

Сайт представляет собой многостраничный информационный ресурс, содержащий четыре раздела: «Главная», «Достопримечательности», «Галерея», «История».

2. Системные требования
Для корректной работы сайта необходимо:

Персональный компьютер, ноутбук, планшет или смартфон.
Установленный современный веб-браузер: Google Chrome, Mozilla Firefox, Microsoft Edge, Opera или Safari (актуальные версии).
Включённая поддержка JavaScript.
Наличие папки с файлами проекта на локальном диске.

3. Запуск сайта
 Локальный режим (основной способ)
Откройте веб-браузер.
Откройте проводник Windows.
Перейдите в папку: C:\Users\admin\OneDrive\Desktop\Nizhniy-site\
Дважды кликните по файлу index.html.

Сайт откроется в браузере, установленном по умолчанию.

4. Навигация по сайту
В верхней части каждой страницы расположено главное меню, содержащее четыре пункта:

Пункт меню	Назначение
Главная	Переход на стартовую страницу со слайдером
Достопримечательности	Просмотр списка главных объектов города
Галерея	Просмотр фотоматериалов
История	Ознакомление с хронологией города
Переход между разделами осуществляется одиночным кликом левой кнопкой мыши по соответствующему пункту меню.

5. Работа с разделами сайта
5.1. Раздел «Главная»
Раздел содержит приветственный текст, слайдер фотографий Кремля (4 изображения) и три информационные карточки с фактами о городе.

Управление слайдером:

Автоматическая смена изображений — каждые 5 секунд.

Ручное переключение — кнопками ❮ и ❯.

Быстрый переход к конкретному слайду — кликом по точке под слайдером.

5.2. Раздел «Достопримечательности»
Раздел содержит перечень из пяти объектов:

Нижегородский кремль

Чкаловская лестница

Улица Рождественская

Нижегородская ярмарка

Нижневолжская набережная

Порядок работы:

Кликните по карточке интересующего объекта.

Откроется модальное окно с подробной статьёй (описание, история, факты, адрес).

Для закрытия окна используйте один из способов:

нажать кнопку-крестик в правом верхнем углу;

нажать клавишу ESC;

кликнуть по затемнённой области вне окна.

5.3. Раздел «Галерея»
Раздел содержит сетку из шести фотографий с подписями.

Порядок работы:

Кликните по интересующему изображению — откроется просмотрщик с увеличенным фото.

Для переключения между фотографиями используйте кнопки ❮ и ❯ либо точки в нижней части окна.

Для закрытия просмотрщика используйте крестик, клавишу ESC или клик по затемнённому фону.

5.4. Раздел «История»
Раздел содержит хронологию из шести ключевых событий истории города.

Порядок работы:

При наведении курсора на блок события отображается всплывающая карточка с портретом и кратким фактом.

При клике по блоку открывается модальное окно с подробной статьёй.

Закрытие окна осуществляется аналогично другим разделам (крестик, ESC или клик по фону).

6. Горячие клавиши

Действие	Клавиша / элемент
Закрытие модального окна	ESC
Переключение слайдера вперёд	Кнопка ❯
Переключение слайдера назад	Кнопка ❮
Пролистывание фотографий в галерее	Кнопки ❮ и ❯
Быстрый переход по слайдам/фото	Клик по точке

7. Возможные неполадки и способы их устранения
Неполадка	Рекомендуемое действие
Изображения не отображаются	Проверить наличие папки images рядом с HTML-файлами, обновить страницу
Слайдер не переключается	Обновить страницу клавишей F5
Модальное окно не закрывается	Нажать ESC или кликнуть по затемнённому фону
Кнопки и ссылки не реагируют	Убедиться, что JavaScript включён в браузере
Сайт отображается некорректно	Обновить браузер до актуальной версии
Файл не открывается	Проверить правильность пути C:/Users/admin/OneDrive/Desktop/Nizhniy-site/index.html

8. Адаптивность
Сайт корректно отображается на персональных компьютерах, ноутбуках, планшетах и смартфонах. Вёрстка автоматически адаптируется под размер экрана устройства.
